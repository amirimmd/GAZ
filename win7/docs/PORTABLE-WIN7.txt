# نسخه پرتابل — ویندوز ۷ (۳۲ بیتی) و ۱۰/۱۱ — نسخه ۲.۳.۱

این پوشه را کامل روی فلش کپی کنید. نصب لازم نیست.

## اجرا

1. روی `Qaemshahr.exe` دوبار کلیک کنید.
2. اولین ورود: کاربر `admin` با رمز پیش‌فرض نصب (صفحه‌کلید انگلیسی) — در همان ورود اول باید رمز را عوض کنید.
3. همه داده‌ها داخل پوشهٔ `AppData` کنار همین برنامه ذخیره می‌شوند.

## مهم

- فایل `portable.flag` را حذف نکنید؛ بدون آن داده به ProgramData سیستم می‌رود و بین سیستم‌ها قاطی می‌شود.
- کل پوشه را با هم جابه‌جا کنید (نه فقط exe).
- قبل از بیرون کشیدن فلش، برنامه را ببندید.
- روی هر سیستم مقصد باید .NET Framework 4.8 نصب باشد.
- نسخهٔ نصب‌شده روی هارد با این پرتابل جداست.
- بستهٔ تحویل نباید از قبل داخل `AppData` پایگاه یا کلید داشته باشد؛ داده فقط بعد از اولین اجرا ساخته می‌شود.

## به‌روزرسانی بدون از دست رفتن داده

1. برنامه را کامل ببندید.
2. از پوشهٔ `AppData` یک کپی پشتیبان بگیرید.
3. با اسکریپت به‌روزرسانی (پیشنهادی):

```
powershell -NoProfile -ExecutionPolicy Bypass -File .\update-portable.ps1 -Source "مسیر\بسته\جدید" -Target "مسیر\پوشه\فعلی\روی\فلش"
```

یا دستی: فقط فایل‌های برنامه (`Qaemshahr.exe`، dllها، `portable.flag`، README) را از بستهٔ جدید روی پوشهٔ قدیمی کپی کنید و **پوشهٔ `AppData` را جایگزین نکنید**.

هرگز کل پوشهٔ پرتابل جدید را روی پوشهٔ کارفرما کپی نکنید؛ `AppData` خالی بستهٔ جدید داده را خراب می‌کند.

## به‌خاطر سپردن رمز

اگر تیک «به‌خاطر سپردن رمز» را بزنید، نام کاربری و رمز به‌صورت **رمزنگاری‌شده (AES)** داخل `AppData\local` ذخیره می‌شود. فایل خام قابل‌خواندن نیست؛ کلید کنار داده در `AppData\keys` است — کل پوشه را از دسترس دیگران دور نگه دارید.

## ساختار

```
QaemshahrPortable/
  Qaemshahr.exe
  portable.flag
  README-PORTABLE.txt
  update-portable.ps1
  AppData/          ← پایگاه، اسناد رمزشده، عکس، کلید، لاگ، بکاپ، local
  (سایر dllها)
```

## پیش‌نیاز ویندوز ۷

- ویندوز ۷ SP1، ۳۲ یا ۶۴ بیت (برنامه x86 است).
- .NET Framework 4.8 و Visual C++ x86 در صورت نبود.
