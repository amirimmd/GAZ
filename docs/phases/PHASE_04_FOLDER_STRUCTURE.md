## Package Responsibilities

| Path | Rule |
|------|------|
| `domain/` | Pure Dart — no Flutter imports |
| `data/` | Implements domain contracts; Drift allowed |
| `presentation/` | Flutter UI only; no SQL |
| `core/security/` | Crypto, hashing, key management |
