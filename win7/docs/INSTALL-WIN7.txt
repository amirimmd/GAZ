# سامانه منابع انسانی قائم‌شهر — نصب آفلاین ویندوز ۷ / ۱۰

نسخه ۲.۲.۰ — یک بسته نصب برای ویندوز ۷ SP1 (۳۲ و ۶۴ بیت) و ویندوز ۱۰/۱۱.

## محتویات پوشه نصب

همه این‌ها باید کنار هم بمانند:

```
QaemshahrSetup_2.2.0.exe
INSTALL-WIN7.txt
redist\
  ndp48-x86-x64-AllOS-ENU.exe          (.NET Framework 4.8)
  vc_redist.x86.exe                    (Visual C++ x86)
  windows6.1-kb4490628-x86.msu         (Servicing Stack — Win7 x86)
  windows6.1-kb4490628-x64.msu         (Servicing Stack — Win7 x64)
  windows6.1-kb4474419-v3-x86.msu      (SHA-2 — Win7 x86)
  windows6.1-kb4474419-v3-x64.msu      (SHA-2 — Win7 x64)
```

## نصب اول (آفلاین)

1. کل پوشه را روی سیستم مقصد کپی کنید (فایل ستاپ + پوشه `redist`).
2. روی `QaemshahrSetup_2.2.0.exe` دابل‌کلیک کنید (دسترسی مدیر لازم است).
3. ستاپ خودش به‌ترتیب پیش‌نیازها را نصب می‌کند:
   - روی ویندوز ۷: KB4490628 → KB4474419 → Visual C++ → .NET 4.8
   - روی ویندوز ۱۰/۱۱: فقط موارد کمبود (معمولاً فقط در صورت نیاز)
4. اگر پیام راه‌اندازی مجدد آمد، سیستم را ری‌استارت کنید و در صورت نیاز ستاپ را دوباره اجرا کنید.
5. ورود پیش‌فرض: کاربر `admin` با رمز پیش‌فرض نصب (صفحه‌کلید انگلیسی، Alt+Shift). در اولین ورود رمز را عوض کنید.

## پیش‌شرط ویندوز ۷

- ویندوز ۷ باید **Service Pack 1** داشته باشد.
- بدون پوشه `redist` کنار ستاپ، نصب روی سیستم تمیز ممکن است متوقف شود.

## محل داده (آپدیت پاک نمی‌کند)

| چیست | کجا |
|---|---|
| برنامه | `C:\Program Files (x86)\GAZ\Qaemshahr` |
| پایگاه داده و اسناد | `C:\ProgramData\GAZ\Qaemshahr` |

## نصب نسخهٔ جدید (آپدیت)

همان فایل ستاپ با شماره بالاتر را اجرا کنید. داده در ProgramData می‌ماند.

## نسخه پرتابل

برای فلش بدون نصب، از بستهٔ `QaemshahrPortable_2.2.0` و فایل `README-PORTABLE.txt` داخل آن استفاده کنید. داده کنار برنامه در `AppData` است؛ هنگام آپدیت آن پوشه را جایگزین نکنید.

## حذف برنامه

حذف پیش‌فرض داده را نگه می‌دارد مگر صریحاً تأیید کنید.

## محدودیت ویندوز ۷

بدون اینترنت: پیامک و اعلان فوری ارسال نمی‌شود. اثرانگشت پشتیبانی نمی‌شود.
